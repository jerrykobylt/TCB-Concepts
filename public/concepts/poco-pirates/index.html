Public schedules

One switch, and the manager holds it

Games come straight from TeamSnap, so nobody edits a web page. Each team manager gets a single switch: on, and their season is public and stays current all year. Off, and nothing appears. Off is the default and they can flip it back any time.

Practices, rosters and player details never go public. Games, divisions, rinks and times — that's all.
